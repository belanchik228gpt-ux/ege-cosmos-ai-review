# Cosmos 0.7.7 — один живой фон и полноэкранный просмотр

## Исправлено

В 0.7.6 большой фон главной страницы был статичным изображением, а видео находилось внутри карточки. Поэтому экран воспринимался статичным и содержал две копии одной сцены. Теперь на главной один общий видеофон; дубликаты внутри карточек удалены. Это относится к «Школе» и «ЕГЭ».

Кнопка **«Смотреть на весь экран»** открывает отдельный просмотр без навигации, карточек, полосы прокрутки и заголовка окна. Сцена заполняет экран. Кнопки автоматически скрываются через 2,8 секунды; движение мыши возвращает их. Доступны смена палитры, пауза/продолжение, запуск с начала, заполнение экрана/показ целиком и выход кнопкой либо Esc. При паузе сохраняется кадр видео, а не подставляется постер.

Ролики автоматически повторяются, пока просмотр открыт. При переходе в просмотр фоновый экземпляр видео выгружается: одновременно работает один ролик. Закрытие восстанавливает доступность основного интерфейса, фокус и прежнюю прокрутку. Вызов полноэкранного режима проверен через настоящий Windows Electron BrowserWindow, а не только CSS-модальное окно.

## Настройки и ограничения

Обычный фон соблюдает настройки движения и качества. Явное нажатие «Смотреть на весь экран» запускает видео отдельно от фоновых настроек; сами настройки не изменяются. Просмотр можно остановить кнопкой «Пауза». Если система не разрешает native fullscreen, просмотр остаётся на всю область окна приложения.

Четыре исходные палитры имеют видео 1920×1080 длительностью 16 секунд. Красная и чёрно-белая по-прежнему представлены изображениями, поскольку видео для них отсутствуют в переданном пакете. Никакие новые ролики или дополнительные эффекты вместо исходной анимации не синтезировались.

## Проверка

`scripts/ton618-review.mjs` запускает собранный EXE в отдельном профиле. Дополнительно к проверкам шести палитр, low/static/reduced motion, перезапуска и окна проверяются:

- Native fullscreen и покрытие всей области 1920×1080 без полосы прокрутки.
- Реальное изменение декодированных пикселей между кадрами, а не только увеличение currentTime.
- Два полных естественных 16-секундных цикла подряд, без перемотки для этой проверки. Бесконечная длительность не может быть фактически протестирована; отсутствие ограничения числа циклов задаёт HTML video loop.
- Пауза без изменения позиции, сохранение видимого кадра, продолжение и повтор с начала.
- Смена палитры внутри просмотра, показ статичного варианта, режим вписывания.
- Esc, кнопка закрытия, снятие inert с интерфейса, возврат фонового видео.
- Реальные скриншоты полноэкранного просмотра и обычных главных страниц.

Отчёты и снимки находятся в `verification/ton618-0.7.7/` и `verification/ton618-installed-0.7.7/`. Проверки файлов установленной версии, медиа и установщика сохраняются отдельно. Обновление приложения устанавливается без повторного копирования моделей; три локальных файла весов восстанавливаются проверенными NTFS hard links. Учебный профиль при установке сравнивается по SHA-256.

Финальный установленный EXE: PASS, 18 скриншотов, ошибок страницы — 0. Размер полноэкранной сцены — ровно 1920×1080. Два естественных цикла прошли за 32,0034 секунды; среднее изменение RGB между декодированными кадрами за 2,5 секунды — 14,84 из 255. TypeScript и production-сборка прошли. Известное предупреждение Vite о большом чанке остаётся. Многочасовая устойчивость воспроизведения и аппаратный запуск без GPU этим прогоном не проверялись.

## Следующий шаг

В приложении открыть «Сегодня» либо «Главная», выбрать видеопалитру и нажать «Смотреть на весь экран». Для красной и чёрно-белой анимаций потребуются соответствующие исходные видео.
