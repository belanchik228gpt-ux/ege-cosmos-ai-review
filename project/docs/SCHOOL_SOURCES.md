# Локальные источники школьного режима

Школьный режим использует отдельный каталог предметов, отдельные учебные данные интерфейса и отдельные папки экспортированных документов. Backend принимает канонические ID из `shared/school-subjects.json`; неизвестный предмет отклоняется, а не заменяется математикой. Поддержаны 12 предметов и доступные для каждого классы 7–11. Химия представлена с 8 класса, обществознание — для 9–11, индивидуальный проект — для 10–11. Технология, ИЗО, музыка, физкультура, ОБЗР и другие иностранные языки в реестр не включены.

## Что поставляется

`resources/school-program/manifest.json` описывает реальные PDF и подготовленный постраничный TXT. На 9 сентября 2026 года проверенный пакет содержит 22 источника, 2678 физических страниц, 28 144 899 байт PDF и 8 384 602 байта TXT. В нём представлены источники для всех 12 предметов: 20 рабочих программ, одно методическое письмо и один нормативный стандарт. Это наличие источника для предмета, а не обещание полного набора готовых уроков. Числа актуального пакета проверяются командой ниже и фиксируются в `docs/verification/release-verification-0.7.0.json`.

Рабочая программа перечисляет содержание и требования курса. Она не является учебником и сама по себе не подтверждает правильность любого ответа модели. Авторские объяснения и упражнения Cosmos сохраняют собственный статус. Методическое письмо по обществознанию `frp-social-transition-2026` имеет `kind: guidance`, `status: official-guidance`; оно не выдается за отдельную ФРП. Для нормативного стандарта предусмотрена отдельная пара `standard` / `official-standard`, для библиографической опоры — `textbook-reference` / `textbook-reference`.

Индивидуальный проект опирается на пункт 11 ФГОС среднего общего образования (`fgos-project-requirements`, физическая страница 27). Сохранён официальный файл ЕДСОО, размещённый в 2023 году; исходный приказ № 413 датирован 17.05.2012. Этот PDF обозначен стандартом, не отдельной рабочей программой и не универсальным поурочным планом для 10–11 классов. Авторский маршрут проекта следует отличать от текста нормативного пункта.

У каждой записи есть исходный URL ЕДСОО, дата проверки, год, класс, тип, число страниц, SHA-256 и размер PDF/TXT. Заголовок сохраняет исходный диапазон классов публикации, например 5–9, при том что доступные классы приложения ограничены 8–9. Номер страницы всегда физический, с единицы; печатный номер внутри PDF может отличаться.

## Подготовка и проверка

```powershell
node scripts/fetch-school-sources.mjs
node scripts/prepare-school-sources.mjs --check
```

Первая команда читает уже полученные официальные PDF и массивы постраничного текста из `tmp/school-program/stem-manifest.json`, `tmp/school-program/humanities/manifest.json` и `tmp/school-program/humanities/project-manifest.json`. Она проверяет исходные SHA-256, размеры, сигнатуру PDF, наличие окончания файла и число извлечённых страниц; затем создаёт пакет PDF/TXT и его манифест. Сетевых запросов эта команда не выполняет. Для повторной подготовки на другой машине требуется соответствующий staging источников. Режим `--check` использует только готовый пакет и работает без staging, Python, модели или интернета.

TXT создаётся из предварительно извлечённых строк физических страниц без пересказа. Манифест хранит диапазоны символов каждой страницы; UTF-16 индексы соответствуют строкам JavaScript, размеры файлов — байтам UTF-8. Контрольная сумма защищает от изменения подготовленного текста, но не доказывает отсутствие ошибок извлечения или смысловую истинность каждого предложения. Все тысячи страниц не проходили отдельную визуальную приёмку backend-агентом.

## IPC

```ts
listSchoolSources(): Promise<CosmosSchoolSource[]>
openSchoolSource(id: string): Promise<{ ok: boolean; error?: string }>
readSchoolSource({ id, page?, query?, maxChars? }): Promise<{
  ok: boolean;
  source?: CosmosSchoolSource;
  fragments?: Array<{ page: number; text: string }>;
  truncated?: boolean;
  error?: string;
}>
```

Чтение принимает только известный ID, физическую страницу, запрос до 300 символов и общий бюджет до 6000 символов (по умолчанию 4500). Явно выбранная страница имеет приоритет, затем выбираются страницы с совпавшими словами запроса. Возвращается не больше трёх отрывков. `truncated` отмечает сокращение страницы либо результата поиска. Если запрос нигде не найден и страница не задана, возвращается пустой список, без выдуманного объяснения. Подготовленный текст проверяется по SHA-256 при каждом чтении.

Произвольные пути, URL и исполняемые команды через эти методы не принимаются. Проверяются нормализованный путь, реальный путь с учётом junction/symlink, размер, тип файла и контрольная сумма. Нарушения уходят в техническую диагностику; обычный интерфейс получает короткую понятную ошибку. Отсутствующая библиотека не блокирует запуск приложения.

PDF открывается по явной кнопке в отдельном окне приложения с sandbox, contextIsolation, без Node/preload, внешних окон и разрешений. Доступна только выбранная локальная копия и внутренние ресурсы PDF-просмотрщика. Загрузка ограничена 15 секундами. При закрытии приложения завершается только принадлежащий библиотеке просмотрщик. Проверки его параметров и очистки выполнялись на тестовом двойнике окна; новая школьная библиотека ещё требует проверки просмотра из окончательного установленного EXE.

## Преподаватель и документы

`generateOpenAITutor` принимает `mode: 'school'` и `grade: 8 | 9 | 10 | 11`. Для этого режима базовые инструкции не навязывают 10 класс и ЕГЭ, учитывают выбранный предмет, допускают английские учебные фразы и код как текст на информатике. Возможности запуска команд и других инструментов остаются выключены. История передаётся только для выбранного разговора; школьный запрос и запрос ЕГЭ создают независимые временные потоки официального runtime. Проверка этого контракта использует явно обозначенный тестовый транспорт, а не выдаёт его ответы за живую модель. Без входа и интернета основной OpenAI-преподаватель недоступен; локальные источники и экспорт от него не зависят.

`exportDocument` принимает те же дополнительные `mode` и `grade`. Школьные файлы сохраняются в `Документы/EGE Cosmos/Школа/<русское название предмета>/<локальная дата>`. Папки ЕГЭ сохраняют прежний формат. TXT, Markdown, HTML, PDF и DOCX используют существующий механизм реального создания файла; успех возвращается после записи, переименования временного файла и проверки размера. DOCX остаётся текстовым экспортом, а тёмный альбом с рисунками и формулами относится к HTML/PDF. В школьных backend-тестах реально записаны TXT/MD/HTML/DOCX для новых маршрутов; визуальная приёмка школьного PDF из установленного приложения выполняется отдельно.

## Выполненные проверки этого изменения

Первичная backend-проверка версии 0.6.0 (исторический состав пакета): 80 тестов в четырёх целевых файлах прошли: 18 проверок предметов и экспорта, 30 проверок локальной библиотеки, 27 проверок OpenAI transport и 5 прежних проверок библиотеки ФИПИ. Среди проверок — все 15 предметов, недоступные классы, изоляция школьного запроса от ЕГЭ, реальные файлы экспорта, подмена TXT/PDF без изменения размера, обход пути через junction, неизвестные ID, ограничение отрывков, отсутствие библиотеки и очистка просмотрщика. Дополнительно `--check` прочитал настоящий пакет источников и подтвердил хеши и отрывки всех 27 записей. Общая сборка, native UI и живой ответ модели в рамках этой проверки не запускались.


Актуальная версия 0.7.0: 12 предметов, 22 документа; контрольные суммы, фрагменты и установленный состав проверены. Полный прогон 806 тестов и дополнительный тест миграции прошли. Запуски реального EXE и настоящие ответы OpenAI описаны в RELEASE_0.7.0.md; исторические числа предыдущего абзаца не относятся к новому пакету.
