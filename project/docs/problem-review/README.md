# Одна задача — одни числа на доске и в проверке

8 сентября 2026 года. Добавлен локальный `ProblemSpec`: исходное и подтверждённое условие, вид задачи, параметры, шаги, ожидаемый ответ и статус проверки. `ProblemScene` строит рисунок и объяснение из этого объекта. Модельный JSON не может подменить числа или объявить произвольный ответ проверенным: `validateProblemProposal` заново разбирает подтверждённый текст.

## Реализовано

Локальный рекурсивный разбор без `eval`/`Function` поддерживает арифметику со скобками и ограниченными целыми степенями, точные обыкновенные и десятичные дроби, процент от числа, площадь прямоугольника и треугольника по основанию/соответствующей высоте, линейные и квадратные уравнения, `|x − c| = r`, а также модуль числового выражения. Дроби вычисляются рационально, корни проверяются подстановкой; для сложных чисел предусмотрен отказ от неподтверждённого результата.

Неоднозначный или неподдерживаемый текст возвращает `clarification` с одним уточнением и без шагов/готового ответа. Смешанные единицы, произвольные две стороны треугольника, деление на выражение с x, уравнение третьей степени и избыточные числа не интерпретируются как знакомый пример. Обратные геометрические задачи пока запрашивают отдельный разбор. Это ограниченный решатель, а не обещание решить любое условие или проверить любой свободный текст.

Рисунки включают сетку с точным числом рядов и столбцов для небольших целых размеров, пару треугольников, долю целого, числовую прямую, графики линейного и квадратного выражения. Для неподходящего масштаба схема помечена как условная. `revealAnswer:false` исключает шаги `result` и `verify`; состояние раскрытого решения не восстанавливается в режиме самостоятельной попытки. Событие `onStepChange` передаёт индекс, общее число шагов, название, вопрос и завершённость для внешней полосы прогресса.

Тесты включают несовпадение 7×4/7×3, точные дроби, знак степени, отрицательные десятичные, все случаи числа корней, подмену JSON/параметров/шагов, восстановление через `parseProblem(confirmedText)`, ограничения размера и вложенности.

Неверное равенство, отрицание, произвольное предложение с подходящим числом и неправильные единицы не подтверждают ответ. На больших числах допуск не расширяется до другого целого.

- **11/11 интеграционных проверок в настоящем интерфейсе приложения**: текущий вопрос 7×3 совпадает с доской; «получится 21 клетка» переводит к следующему заданию; собственное условие 7×4 строит другую сетку; «будет площадь 28 см2» принимается; условие восстанавливается после перезагрузки. ## Границы и следующий шаг

Эти новые серии сняты в headless Chrome по исходникам; **новая нативная сборка в этом отчёте ещё не проверена**. Распознавание фотографии, настоящие ответы локальной модели и установка проверяются отдельным владельцем desktop-модуля. Сцена принимает текст после подтверждения, а не доверяет распознаванию без проверки.

После первого интеграционного просмотра композиция улучшена: владелец UI уплотнил верхний прогресс, а `ProblemScene` теперь использует container-query. При ширине панели **723,5 px** SVG занимает **673,5 px**; сам прямоугольник имеет ширину **390 px**. Объяснение и формула расположены под рисунком, кнопки остаются внутри панели. Обе обновлённые математические страницы лично просмотрены. Длинная сцена требует вертикального прокручивания на экране высотой 720; крупный рисунок не уменьшается до размера иконки ради размещения всей страницы без прокрутки.

У второй задачи про рынок при просмотре отображалась общая схема «условие — рассуждение — вывод», а не конкретная иллюстрация равновесия 100/100. Данные задачи и проверка соответствуют друг другу; это замечание передано владельцу `TaskBoard`, данный отчёт не приписывает этому компоненту изменение содержания без новой проверки.
