# Передача TON 618 из Unreal Engine 5

Приложение не встраивает Unreal Runtime. Из UE5 нужно экспортировать зацикленную анимацию и статичный кадр. Исходный UE-проект с Content/Config/Plugins хранится отдельно для последующих правок; в EGE Cosmos импортируется только пакет визуальных файлов.

Рекомендуемый исходный экспорт: PNG/EXR последовательность кадров, 20–40 секунд медленной бесшовной анимации, без текста интерфейса, резких вспышек и движения камеры, мешающего чтению. Из мастера подготовить MP4/H.264 или WebM и неподвижное PNG/JPG/WebP. Проверить реальное декодирование формата в сборке перед передачей окончательного пакета.

```text
ton618/
  manifest.json
  preview.webp
  static.webp
  high.mp4
  medium.mp4
  low.mp4
```

```json
{
  "id": "ton-618-unreal",
  "title": "TON 618",
  "author": "Автор сцены",
  "createdWith": "Unreal Engine 5",
  "version": "1.0.0",
  "preview": "preview.webp",
  "static": "static.webp",
  "variants": {
    "high": "high.mp4",
    "medium": "medium.mp4",
    "low": "low.mp4"
  }
}
```

High: до 3840×2160, medium: 1920×1080, low: 1280×720. Это рекомендации, не требование к исходной сцене. Нагрузку и качество нужно замерить после получения настоящего файла.

В приложении: «Каталог фонов» → «Импортировать пакет» → выбрать каталог. Файлы копируются в каталог приложения, внешний исходный пакет не изменяется. При reduced motion, static-качестве или ошибке воспроизведения используется статичный кадр. Пути вне пакета и исполняемые файлы не принимаются.

Отметка «Создано в Unreal Engine» появляется для пакета с соответствующими метаданными. Пользователь или автор пакета отвечает за достоверность метаданных: приложение не доказывает происхождение видеокадров криптографически.

Свободное управление камерой и физикой исходной UE-сцены не переносится в видео. Для такой интерактивности потребуется отдельный движок сцены, а не импорт фонового ролика.

Перед передачей исходников укажи точную версию UE5, плагины и лицензии сторонних материалов. Пока настоящий TON618 не получен, используются оригинальная SVG-композиция Cosmos и статичный тёмный фон без отметки Unreal.
