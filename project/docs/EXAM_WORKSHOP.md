# «Как решать ЕГЭ»: проверенный каталог позиций 2026

Модуль `src/domain/exam-workshop.ts` описывает **94 позиции четырёх экзаменов**. Это каталог форматов и способов подготовки к номерам, а не 94 готовых официальных задания, не банк всех вариантов и не автоматический эксперт по развёрнутым ответам. Названия карточек и советы — авторские. Требования и максимальные баллы изложены по окончательным материалам ФИПИ 2026 года.

| Экзамен                     | Позиции | Краткие / развёрнутые | Максимум первичных баллов |
| --------------------------- | ------: | --------------------- | ------------------------: |
| Математика, базовый уровень |    1–21 | 21 / 0                |                        21 |
| Русский язык                |    1–27 | 26 / 1                |                        50 |
| История                     |    1–21 | 12 / 9                |                        42 |
| Обществознание              |    1–25 | 16 / 9                |                        58 |

Количество строк, порядок номеров и баллы сверены с приложениями спецификаций; страницы приложений реально отрендерены и просмотрены. Форматы дополнительно сверены с демоверсиями. В отдельных позициях возможны разные формулировки: это явно обозначено, содержание одного примера демоверсии не объявлено единственным содержанием номера.

## Происхождение данных

Проверка **9 сентября 2026 года** по [официальной странице ФИПИ](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory). Опубликованные на той же странице **проекты 2027 года не смешаны** с окончательной редакцией 2026.

Все номера страниц в API — **физические страницы PDF, начиная с 1**. Некоторые PDF содержат два печатных разворота на одной физической странице, поэтому номер внизу документа может отличаться. `pages` включает приложение и раздел оценивания спецификации; `demoPages` относится к отдельному PDF демоверсии внутри того же архива. `sourceDocumentId` соответствует существующему манифесту локальных источников; архивная ссылка ведёт на ФИПИ, а не на поисковую выдачу.

Архивы повторно скачаны для сверки демоверсий в `tmp/pdfs/exam-workshop`, с конечным тайм-аутом; PDF проверены по сигнатуре. Локальные спецификации сверены по SHA-256 с существующим манифестом. Временные ZIP, извлечённые PDF, текст и исследовательские рендеры не добавляют новые материалы в поставляемые 22 PDF и не являются пользовательскими документами. Данные исходного локального манифеста не изменялись.

Коды содержания и требований перенесены там, где их смысл и принадлежность позиции подтверждены. Для базовой математики повторно используется `baseExamTaskMap`: широкий код раздела не разворачивается в утверждение, что каждый профильный подпункт входит в базовый экзамен. В обществознании диапазон кодов не возвращает в экзамен выделенные в кодификаторе непроверяемые элементы. Связи `topicId` с отдельными уроками не выдумываются.

## Что именно получает ученик

Для каждой позиции предусмотрены короткое авторское название, формат записи ответа, содержательное требование, максимум первичных баллов, два конкретных совета с типичными ошибками, источник и страницы. Частые ошибки здесь — авторский педагогический список, **не статистический рейтинг ошибок ФИПИ**.

Существенные проверенные особенности редакции 2026:

- Вся базовая математика имеет краткий ответ. Рукописный лист в приложении помогает учиться, но экзаменационный черновик не оценивается.
- В русском № 7 охватывает грамматические нормы шире одной морфологии; № 22 посвящён средствам выразительности, № 26 — связи предложений. № 8 и № 22 дают один балл при одной **или двух** ошибочных позициях соответствия. Сочинение № 27 имеет максимум 22; при 149 словах или менее оно получает ноль по всем критериям. Неверная позиция автора по К1 влияет на К2 и К3.
- В истории № 11 связывает текст и карту и в демоверсии требует название города, а не набор цифр. № 13 и № 14 запрашивают по три элемента при максимуме два балла. Для № 15 и № 16 нельзя механически считать любой один элемент равным одному баллу: в демоверсии есть зависимость от верной атрибуции/выбора изображения. № 19 отделяет определение от конкретизирующего факта, № 20 — тезис от двух обоснований, № 21 — российский аргумент от аргумента по всеобщей истории.
- В обществознании № 3 — соответствие с максимумом **один** балл. В № 24 четвёртый балл за корректность формулировок возможен только при полном результате по раскрытию темы. Для № 25 отдельно описаны обоснование, ответ на вопрос и примеры. Конкретные обязательные признаки и аспекты плана зависят от условия.

Подробные разборы отдельных критериев обозначены словами «в демоверсии». Карточки не заменяют полные критерии конкретного варианта, включая зависимости элементов, допустимые синонимичные формулировки и снижение за лишние ошибочные позиции. Максимум первичных баллов не является обещанием оценки от Cosmos, тестового балла или результата 80+.

## API и границы тренировки

```ts
getExamTasks(subject: SubjectId): ExamWorkshopTask[];
getExamTask(subject: SubjectId, number: number): ExamWorkshopTask | undefined;
examTrainingInstructions(task: ExamWorkshopTask, count: number, current = 1): string;
```

Публичный тип также экспортируется под именем `ExamTaskCard`. Номера начинаются с 1 отдельно для каждого предмета, идентификаторы имеют вид `exam-2026-math-1`. Получаемые массивы копируются, чтобы изменение карточки в UI не испортило общий реестр. Неверный номер возвращает `undefined`.

Инструкции тренировки используют повторно найденную каноническую карточку, а не непроверенные поля вызывающей стороны. Количество ограничено диапазоном 1–30 (по умолчанию 10 для некорректного числового значения); текущая позиция также ограничена диапазоном серии. Требуется один пример за раз, самостоятельная попытка, небольшая подсказка при затруднении и итог только по реальным попыткам. Явно запрещено просить анализировать отсутствующий текст или рисунок, выдавать придуманный исторический источник за настоящий, объявлять свободную модельную оценку официально подтверждённой и засчитывать раскрытый ответ как самостоятельный.

Функция создаёт **инструкцию**. Сама по себе она не генерирует примеры, не сохраняет счётчик серии, не гарантирует соблюдение инструкций моделью и не присваивает прогресс. Жизненный цикл серии, реальные ответы модели, лист решения, экспорт и UI проверяются отдельно основной задачей.

## Отчёт по этому модулю

- **Сделано:** все 94 позиции; содержательные требования и авторские советы; подтверждённые форматы, баллы и источники; ограниченная инструкция тренировки; отдельные пояснения к сложным критериям.
- **Проверено:** приложения четырёх спецификаций и соответствующие демоверсии; реальные рендеры страниц таблиц; 13 доменных тестов; `tsc --noEmit`. Тесты проверяют полноту нумерации, суммы баллов, происхождение, различия редакции 2026, изоляцию данных и честность инструкции.
- **Заблокировано:** для статического каталога препятствий нет. Экспертное подтверждение результата конкретного развёрнутого ответа требует его условия, материала и критериев; без них нельзя выдавать точные официальные баллы.
- **Не реализовано этим модулем:** локальный банк всех вариантов, автоматический официальный эксперт, гарантия правильности свободной генерации, UI, сохранение серии, экспорт, новый native smoke. Наличие карточек не означает проверку 94 сгенерированных упражнений.
- **Следующий шаг:** интеграционная приёмка раздела и серии на настоящих ответах; отдельно проверить доступность исходных материалов для задач по тексту/карте/диаграмме, сохранение номера примера и честный итог.
