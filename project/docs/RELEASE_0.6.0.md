# Cosmos 0.6.0 — отдельный школьный режим

Статус на 09.09.2026: версия 0.6.0 собрана, установлена и прошла ограниченную приёмку, описанную ниже. Это выпуск работающего школьного режима; полнота и педагогическая проверка всех многозанятийных курсов не заявляются.

## Изменения

Постоянный переключатель «Школа / ЕГЭ» разделяет два маршрута. Школьный режим включает математику, русский язык, литературу, английский язык, историю, обществознание, географию, физику, химию, биологию, информатику, ОБЗР, физическую культуру, музыку и индивидуальный проект. Музыка доступна в 8-м классе, обществознание — с 9-го по переходным документам 2026/27, индивидуальный проект — в 10–11-м. Технология, ИЗО и остальные иностранные языки исключены по выбору пользователя.

337 разделов каталога связаны с физическими страницами официальных документов. Содержание показано в раскрывающихся карточках; поиск находит слова внутри подпунктов. Из карточки можно начать раздел, отдельную подтему, диагностику или разбор домашней работы. Для 10–11 классов выбран базовый школьный уровень; это не уровень базового ЕГЭ.

План распределяет выбранные предметы на день, неделю или месяц. Существующие дни и записи другого класса сохраняются. Можно добавлять темы, вписывать свою задачу, менять минуты и порядок. Занятие связано с конкретной записью и датой; два домашних задания одного раздела не завершаются одновременно.

Школьный преподаватель использует существующее подключение OpenAI и отдельные инструкции предмета/класса. Доступны обычная переписка, PNG/JPEG, рисунки сцен и электронный лист для математики. Контекст берётся только из школьных занятий этого предмета и класса. В конце сохраняется предварительный итог, в том числе по домашней работе. Окончание занятия не подтверждает освоение раздела: пользовательская отметка «разобрано» служит планированию.

Без подключения работают каталог, локальные вводные карточки, примеры с ответом для самопроверки, план, память и документы. Свободная проверка произвольного ответа в школьном диалоге требует подключённого OpenAI. Ответы модели не выдаются за проверенные факты учебника.

Конспект собирается из авторской вводной, реальной переписки, личной заметки и рисунков. Черновик можно редактировать; файл появляется после экспорта. Школьные документы хранятся отдельно по предмету и дате. HTML/PDF сохраняют тёмный учебный стиль и рисунки, DOCX — текстовый формат, также доступны MD/TXT.

## Источники и пределы покрытия

Локальная библиотека содержит 27 официальных PDF: 25 ФРП, методическое письмо по обществознанию и ФГОС с требованиями к индивидуальному проекту. Это 3478 страниц. Есть 13 библиографических ссылок издателя. Полные защищённые тексты учебников не загружены и не выдаются за прочитанные источники.

Состав предметов и страниц проверен. Авторская вводная и один вопрос на раздел — старт обучения, а не полностью написанный и проверенный многозанятийный курс. Рисунки создаются из проверяемых структурированных данных через существующие семь семейств локальных сцен; уникальная режиссура каждой подтемы не заявляется. Правильность каждого будущего ответа OpenAI и освоение программы этими проверками не гарантируются.

Подробности: [STEM](SCHOOL_PROGRAM_STEM.md), [гуманитарные предметы](SCHOOL_PROGRAM_HUMANITIES.md), [локальная библиотека и API](SCHOOL_SOURCES.md).

## Воспроизводимость

После клонирования репозитория выполните `node scripts/fetch-school-sources.mjs`: PDF загружаются только по официальным адресам и принимаются только при совпадении записанных размеров и SHA-256. Текст и манифест входят в репозиторий. Затем `node scripts/prepare-school-sources.mjs --check` проверяет целостность и чтение фрагментов.
