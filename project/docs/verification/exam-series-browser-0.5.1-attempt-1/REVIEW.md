# Сохранённый FAIL до исправления подписи старого фото

Контролируемый headless backend, не живой OpenAI. После разбора первого математического листа было прикреплено новое фото `previous-example.png`, затем нажат «Следующий пример». Передача старого PNG была правильно предотвращена, но новая пользовательская реплика получила ложное `imageName` этого фото. Проверка остановилась с `New-example message falsely labels the old unsubmitted photo`.

Отчёт и failure.png сохранены без подмены результата. Исправление одной строки CloudRoom и полный последующий PASS находятся в соседней папке `exam-series-browser-0.5.1`.
