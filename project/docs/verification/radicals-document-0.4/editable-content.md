## Учебный разворот

Квадратный корень выбирает неотрицательное значение. Поэтому корень из квадрата числа равен его модулю. Сначала сохраняем модуль, затем учитываем знак выражения внутри.

### Определение

√(a²) = |a| для действительного a. При a < 0 получаем −a; при a ≥ 0 — a.

### Полезный приём

Упростить — изменить запись, сохранив значение. Минус перед скобкой меняет знак каждого слагаемого.

### Формула или вывод

(x ± c)² = x² ± 2cx + c²; √((x − c)²) = |x − c|.

### Разобранные примеры

Авторские учебные примеры Cosmos. Это разборы для обучения, а не решения или результаты ученика.

### Пример 1 · Корень из квадрата

Упрости √((x − 6)²), если x < 6.

1. Получаем |x − 6|. При x < 6 внутри отрицательное число.

2. Берём −(x − 6), раскрываем скобки: −x + 6.

Ответ: 6 − x, или −x + 6

### Пример 2 · Узнать квадрат

Упрости √(x² + 8x + 16), если x ≥ −4.

1. x² + 8x + 16 = (x + 4)², поэтому корень равен |x + 4|.

2. При x ≥ −4 внутри неотрицательное число. Модуль оставляет его.

Ответ: x + 4

### Сохраняем знаки при перестановке

Почему −x + 6 можно записать как 6 − x?

1. В сумме знак принадлежит слагаемому: здесь это −x и +6.

2. Переставляем целые слагаемые: +6 + (−x). Минус остаётся при x.

3. Такая перестановка не находит значение x; она даёт равную запись.

Ответ: −x + 6 = 6 − x

## Ошибки, которых можно избежать

- Не теряй корень, пока преобразуешь выражение под ним.

- Не меняй знаки внутри скобки раньше её раскрытия.

- При сокращении удаляй только одинаковые ненулевые множители.
