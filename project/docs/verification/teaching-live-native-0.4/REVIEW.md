## Границы и следующий шаг

Подтверждена работа небольшого набора маршрутов и реальной модели, а не универсальное понимание любых вопросов. Рекомендованный следующий шаг — сделать прямой смысловой переход для «что означает чему равно» к зарегистрированному простому примеру и не позволять planner возвращать его к прежнему вопросу без разбора затруднения. Замечание передано root; продукт этим агентом не менялся.
