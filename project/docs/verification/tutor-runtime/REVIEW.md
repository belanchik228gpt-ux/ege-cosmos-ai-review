Самостоятельная оценка педагогики приведена отдельно ниже. Последующие прогоны описаны отдельно: первый транспортный успех не переносится на изменённый код.

**Педагогическая приёмка не объявляется полной.** Ограничение модели остаётся: системная просьба не повторять уже названный факт не гарантирует содержательного следующего вопроса. Это видно в математике и русском. Модель также не объяснила математический механизм настолько конкретно, насколько позволяет сцена с рядами. Для улучшения нужен явный учебный шаг из проверенного материала и контроль содержательного следующего действия, а не отключение сверки ради ответа.

Проверка цитат подтверждает происхождение приведённой строки, но не доказала все утверждения: в математическом ответе упомянут периметр, хотя единственный переданный фрагмент говорит о площади и не содержит определения периметра. Самопроверяющая модель всё равно одобрила кандидат на основании верной формулы площади. Это наблюдаемая граница метода `local-model-review`, а не гарантия проверки каждого утверждения. Источник `cosmos-training` в этой задаче помечает авторский проверенный пример; ФИПИ ему не приписывается.

Новый `getTutorResponse` выполняет структурную сверку цитат через backend и числовую проверку `reviewEvidenceNumbers`. В нём на момент прогона нет отдельного вызова прежнего `reviewTutorResponse` с узкими правилами для известных противоречий. Это различие передано root для оценки интеграции; UI или правила этим QA-скриптом не изменялись. На трёх приведённых ответах ошибок замены условия и ложного отказа модели не обнаружено.

Скрипт завершил собственный worker. Наличие этих результатов не означает успешное распознавание рукописных заданий, идеальный преподавательский диалог или визуальную проверку финального EXE.

## Повтор после отмены обязательного вопроса

В системной инструкции обнаружен прямой конфликт: требование ровно одного вопроса в конце ответа вынуждало модель придумывать повтор даже при полном объяснении. Оно удалено, как и заученные подсказки про век или количество клеток, не связанные с текущим заданием. Прямое «почему» теперь требует причины; вопрос допустим только для следующего самостоятельного шага. Учебный слой добавил объяснение повторения одинаковых рядов.

Повтор 17:09 записан в [after-question-policy-first.json](after-question-policy-first.json) и **не прошёл**:

- Русский стал коротким корректным объяснением без повторного вопроса.
- Математическое объяснение отклонено строгим сравнением цитат. Дополнительный диагностический запрос показал: модель изменила начальную строчную «умножение» в источнике на заглавную «Умножение» в цитате. Даже при двух других точных цитатах такой ответ не допускается. Регистр сравнения не ослаблен. Корректировка авторского фрагмента в отдельное предложение решает наблюдаемый случай, но не гарантирует точного цитирования любых материалов.
- Обществознание выдало неверное последнее утверждение «Спрос не уменьшается, а сдвигается» в контексте изменения цены самого товара. Проверяющая модель одобрила настоящие цитаты, которые этому утверждению не соответствуют. Дефект передан root для проверки предметным правилом; вся предметная часть не объявляется принятой на основании `supported`.

Скрипт теперь сохраняет реальные completion и review для диагностических контрольных случаев. Ключи, HTTP-заголовки и изображение ученика не записываются. Production backend по-прежнему не возвращает отклонённого кандидата в пользовательский интерфейс.
