# Проверка установленного приложения — подготовленный сценарий

**Сценарий уже выполнен:** [результат четырёх запусков](installed-visual-run/run.json), [завершённый личный просмотр](FINAL_VISUAL_REVIEW.md). Текст ниже — сохранённый план до запуска, не актуальное ожидание.

Сценарий подготовлен после заморозки исходников. **Эта страница не является отчётом об успешном запуске.** До завершения установки и сигнала основного агента приложение не запускалось.

Цель: `C:\new cosmos\test-results\installed-app\EGE Cosmos.exe` через переменную `COSMOS_EXE`. Команда после сигнала: `node scripts/run-installed-visual-review.mjs`.

Последовательно, с закрытием каждого окна и отдельным профилем:

1. `docs/interface-review/motion-proof.mjs`: реальные hover/press/focus, переход страницы, reduced motion приложения/системы, выключение эффектов, ручной старт сцены с настроенной скоростью; два восьмисекундных замера rAF/Long Tasks во время настоящего воспроизведения high/low.
2. `scripts/all-native-scenes.mjs`: 13 авторских сцен через учебные комнаты, автостарт, ручной предпоследний шаг, реальные PNG для личного просмотра.
3. `docs/scene-review/motion-v2/native-pause-proof.mjs`: промежуточные состояния прямоугольника/медианы, побайтовое сравнение PNG на паузе и изменение после продолжения; клавиши, оглавление, узкое окно, фокус и промежуточный документ реформы.
4. `docs/scene-review/motion-v2/label-sync-proof.mjs`: синхронное движение подписи M и точки, остановка между начальной/конечной координатами, неизменные пиксели на паузе.

Каждый журнал записывает путь фактически запущенного EXE и SHA-256 его соседнего `resources/app.asar`. Объединяющий сценарий проверяет неизменность SHA перед каждым запуском и после последнего. При заданном `COSMOS_EXPECTED_ASAR` проверяется именно этот ожидаемый хеш. `--disable-backgrounding-occluded-windows` — тестовый аргумент, не изменение настроек обычного запуска. Локальная модель в сценариях не используется.

Для проверки пикселей учебной паузы декоративное фоновое движение отдельно отключается **через настройку приложения**. Это исключает изменение пикселей прозрачной подложки сцены из-за внешней дымки. Проверка живого фона и неона выполняется отдельно первым сценарием. Сам движок сцены, его таймер и анимации не подменяются.

Папки результатов:

- Интерфейс: `docs/interface-review/native`.
- Сцены: `docs/screenshots/installed-final/scenes`, журнал `docs/verification/installed-final-scenes.json`.
- Пауза и подпись M: `docs/screenshots/installed-final/motion`.
- Порядок, exit codes и stdout/stderr: `docs/verification/installed-visual-run`.

После выполнения потребуется лично просмотреть полученные изображения и дополнить `docs/SCENE_REVIEW.md` и `docs/interface-review/README.md`. Успешный exit code не заменяет визуальную приёмку. Измерения rAF описывают интервалы вызовов renderer, а не предъявление кадров GPU; короткий прогон не доказывает постоянные 60 FPS, работу с одновременно генерирующей моделью или производительность всех устройств.
