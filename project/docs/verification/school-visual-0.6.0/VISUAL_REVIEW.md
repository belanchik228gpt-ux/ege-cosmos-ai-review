# Ручной просмотр 0.6.0

Просмотрены реальные снимки packaged EXE, отдельно от результатов DOM/assertions. Ранний live-прогон в `../school-native-0.6.0` функционально прошёл, но его рисунки физики/химии содержали социальные символы. Они не приняты как финальный визуал.

В текущих `physics-force-corrected.png` и `chemistry-electrons-corrected.png` проверены тело со стрелкой результирующей силы, исходные значения и подписи, четыре/один внешних электрона, формулы и читаемость русского пояснения. Старый рисунок можно переиграть после следующего ответа. Интерфейс оставляет широкую область разговора. В `chemistry-low-reduced-motion.png` сохранены данные и ручные шаги.

Полный экран функционально проверен, ранний снимок сделан во время появления первого кадра. В installed-проверке runner дожидается видимого кадра. Новый снимок `../school-installed-0.6.0/physics-fullscreen.png` просмотрен: оба значения, подписи единиц, текущая формула и управление читаемы и помещаются на экране. Также просмотрены установленная схема силы и химическая сцена.

Повторно экспортирован `physics-corrected.pdf` (558576 байт, шесть альбомных страниц A4). Все шесть PNG `pdf-page-1`–`pdf-page-6` просмотрены. Показаны пять кадров двух реальных модельных сцен, формулы, переписка, итог и источники. Числовые данные сохраняются; схема силы не заменяется списком названий. Блок ASCII из ответа напечатан моноширинно, без служебных ограждений кода. Текст и формулы не перекрываются и не обрезаны. Сохранённые кадры статичны; они не являются видеозаписью анимации.

Также просмотрены каталог, 1280×720 и узкое окно 850×820 раннего native-прогона: карточки и навигация остаются читаемыми, горизонтального переполнения не обнаружено. Windows scaling 200%, отсутствие GPU и длинная многочасовая сессия в этой проверке отдельно не воспроизводились.

`failure.png` оставлен как свидетельство промежуточной ошибки самого runner: проверялось несуществующее поле `available` источника. Runtime API возвращает метаданные доступных источников; исправленный runner реально читает фрагмент каждого из 27 документов. Итог этого исправления находится в `report.json`.
