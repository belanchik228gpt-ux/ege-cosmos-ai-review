# Проверка нового учебного маршрута через интерфейс

Сценарий: `node scripts/study-flow-review.mjs`. Адрес по умолчанию — локальный Vite `http://127.0.0.1:5173`; можно задать `COSMOS_TEST_URL`. Используется настоящий headless Chrome и отдельный постоянный профиль в `test-results`. Учебное состояние не подставляется скриптом: все изменения выполняются кнопками и полями приложения. `result.json` содержит время последнего прогона, фактические проверки, бюджет, попытки и размер каждого снимка.

Проверено:

- Первый вход: 10 класс, базовая математика, 120 минут; четыре предмета присутствуют в дневном плане, перерывы входят в бюджет.
- Школьная запись «Модули и уравнения с модулем» открывает настоящий урок `math-absolute` одной кнопкой начала дня. Автоматический хвост сокращён, бюджет не увеличен.
- Четыре проверенные попытки: одна ошибка, два верных ответа с помощью, один самостоятельный верный ответ. «Не знаю» даёт подсказку и не становится самостоятельным успехом. Другие предметы не получают этих попыток, тема не объявляется освоенной.
- Возврат из настроек, материалов и календаря сохраняет идентификатор занятия, индекс задания и остановленный второй шаг сцены.
- Пауза/продолжение дня, ручное завершение двух учебных блоков, переход через один перерыв к следующему блоку.
- Досрочный итог содержит четыре реальные попытки и одну ошибку с разбором. Второй вручную завершённый блок имеет ноль попыток; это явно не подтверждение освоения. Незапущенные и начатые незавершённые блоки различаются.
- Переключение недели/месяца, заполнение свободных дней, добавление личной темы, изменение её времени с 20 на 15 минут и перенос на другую локальную дату.
- Попытка переноса в заполненный день отклоняется без изменения бюджета или потери исходной темы. Затем пользовательским действием удаляется автоматический блок целевого дня; повторный перенос проходит. Точный текст отказа сохранён в JSON.
- Новая краткая диагностика предлагает уравнение с модулем, проценты и произведение дробей. Три самостоятельных ответа (`2`, `200`, `6/35`) сохранены отдельно от попыток урока; кнопка итога открывает личный план.
- Chrome действительно закрывается и запускается заново с тем же профилем. Календарь, личная тема, учебные попытки, диагностика и итог дня совпадают с сохранённым состоянием.
- Снимки из интерфейса при viewport 1280×720 и 390×844. Горизонтального выхода за экран нет. Длинный календарь прокручивается вертикально; `fullPage` PNG намеренно выше экрана.

В первом проходе найден реальный дефект доступности: на узком экране подписи навигации скрывались CSS, оставляя четыре иконки без доступных имён. В App добавлены `aria-label` и `title`, после чего переход к плану при ширине 390 проходит. Прежний `failure.png` показывает состояние этого раннего прогона; это исторический материал, а не результат последней проверки. Подробные JSON прежних попыток находятся в соответствующих изолированных профилях `test-results`.

Лично просмотрены PNG урока, досрочного отчёта, диагностики, главной и плана на узком экране. Перед итоговыми снимками старое уведомление об отказе по бюджету закрывается обычной кнопкой интерфейса, после сохранения текста отказа в JSON.

Границы проверки:

- Этот каталог подтверждает браузерный интерфейс, а не установленный EXE. Тот же скрипт поддерживает `COSMOS_EXE`; его отдельный результат появится в `study-flow-native` только после фактического запуска.
- В браузере нет desktop bridge, модель не запускается. Ответы здесь — реальные проверки локальных заданий, не live LLM и не проверка качества модели.
- Headless Chrome не подтверждает корректность детектора фокуса Windows. В этом коротком прогоне счётчик активности может оставаться нулевым; проверка паузы подтверждает отсутствие роста счётчика во время паузы, а не точность нативного таймера.
- Прохождение этих сценариев не означает полноту учебной программы или освоение тем. Для каталожных тем без связанного урока сохраняется честный режим обзора.
- Native shell имеет минимальную ширину 620 px. Нативный вариант скрипта снимает его на 620 px и не выдаёт этот результат за проверку 390 px.
