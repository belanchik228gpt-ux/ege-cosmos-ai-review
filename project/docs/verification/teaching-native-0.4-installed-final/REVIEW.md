# Проверка учебного диалога в EGE Cosmos 0.4

8 сентября 2026. Настоящий упакованный `test-results/installed-app/EGE Cosmos.exe`, отдельный профиль, локальная модель отключена в этом прогоне. Сценарий: `scripts/teaching-native-review.mjs`. Результат: **13/13 проверок поведения**; подробности в `result.json`.

SHA-256 `resources/app.asar`: `375ff6d3937fbd7e4a0232692433c94d45cf3571cac4e8467aa0492489b982c3`. Прогон сделан после обновления файлов существующей установки; фактический запуск окончательного NSIS и последующий диалог с моделью проверяются отдельно.

## Что проверено

- Пропуск задания не создаёт успешную попытку. Для `|x| = 0` подсказка регистрирует отдельный вопрос о координате. `0? я не знаю(` принимается именно для него; затем можно продолжить обсуждение количества корней.
- Определение корня открывается как отдельный простой пример со своим вопросом, рисунком и возвратом. Решение с помощью остаётся решением с помощью.
- После раскрытого разбора можно перейти дальше без переписывания готового ответа. Следующее условие и сцена синхронизированы.
- Новый урок о корнях начинается с небольшого объяснения. Равные записи выражений принимаются; завершение цепочки не требует дублирования результата.
- В настоящем окне проверены autoplay, пауза, повтор, шаг назад и скорость. При паузе геометрия и время анимаций сохраняются. Между двумя декодированными изображениями максимальное отличие канала — **1 из 255**; это не побайтовое равенство снимков. Измерения сохранены в `pause-metrics.json`.
- Проверены 1920×1080, 1280×720, узкое окно, масштаб приложения 200% и reduced motion. На 1920×1080 поле ответа и отправка помещаются в видимую область. Узкая раскладка и 720p используют прокрутку; это не проверка всех режимов Windows DPI.
- Настоящий перезапуск сохраняет текущий подшаг и учебные попытки. Четыре предметные комнаты изолированы; доски русского языка и обществознания используют фактическое условие.

## Визуальное свидетельство

Снимки сделаны из работающего EXE через Playwright Electron, без подмены CSS и без синтетического изображения интерфейса. При финальном просмотре отдельно открыты `02-coordinate-step-viewport.png`, `04-meaning-of-root-viewport.png` и `08-radical-animation-viewport.png`: актуальные вопрос, иллюстрация, пояснение и поле ответа читаются, прежних универсальных значков 1/2/? в этих состояниях нет. Остальные широкие, узкие и предметные состояния сохранены рядом с машинным отчётом; вывод о качестве всего курса из этих трёх кадров не делается.

Этот прогон проверяет учебный контроллер и реальное отображение. Он **не** проверяет качество свободного ответа модели, OCR, произвольные задачи или весь кодификатор. Для живой модели, собственных задач, документов и установщика есть отдельные отчёты.
