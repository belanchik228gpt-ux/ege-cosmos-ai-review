# Смысловые учебные сцены

8 сентября 2026 года. Новый `TeachingScene` строит локальные SVG по ограниченному `TeachingVisual`, а не получает HTML или CSS от модели. Источник типов — `src/domain/teaching-visual.ts`; контроллер обучения передаёт конкретные значения, вопрос и авторский пример.

## Сделано

Реализованы расстояние до точки отсчёта, нулевое расстояние, число различных корней, отрицательная запрошенная длина, сдвинутое уравнение с модулем, вычитание на числовой прямой, знак выражения из ограничения, сравнение числа с корнем и авторская цепочка преобразований с подсветкой частей.

Сцена использует общий `useSceneClock`: autoplay, пауза посреди движения, продолжение, повтор, назад/вперёд, скорость 0,5–2×, внешний pause, reduced-motion, high/medium/low/static и сохранение позиции по ключу. Полоса «кадр объяснения» не изменяет учебный прогресс. `onStepChange` отдаёт индекс и стадию `orient/build/compare/conclude` для внешнего контроллера.

После исправления 8 сентября в 19:41 МСК `revealAnswer=false` больше не останавливает числовой рисунок на исходном кадре: путь, схождение маркеров, граница допустимых длин и знак строятся по стадиям. Скрыты только итоговая формула, число различных корней и подписи вычисленных координат. Ученик может рассуждать по построению. Числовая шкала остаётся видимой. Цепочка преобразований самостоятельного примера содержит только исходную строку. Явный `revealAnswer=true` открывает решение. Авторский `workedExample:true` позволяет показывать все преобразования другого объясняющего примера с отдельной подписью. Этот флаг задаёт проверенный контент, а не модель. Условие `expression.condition` остаётся над цепочкой на каждом кадре; например, переход к `−x + a` сопровождается условием `x < a`.

## Границы

Это компонентный браузерный стенд, **не новая нативная проверка EXE** и не проверка подключённого контроллера занятий. Модель и распознавание фотографии не вызывались. Собственный браузер и Vite 5177 закрыты после прогона.

Числовые семейства рассчитывают координаты и выводы локально по переданным значениям. Для `expression` валидируются форма, размер и безопасный вывод текста; произвольная цепочка не становится математически доказанной от прохождения этого валидатора. Правильность цепочки и постоянных условий остаётся обязанностью авторского учебного контента. Положение неизвестного x в сцене знака отмечено как условное, положение корня на оси — приближённое.

Следующий шаг: подключение к состоянию учебных шагов, затем отдельные интеграционные и нативные кадры собранного приложения. Эти результаты не заменяют их.
