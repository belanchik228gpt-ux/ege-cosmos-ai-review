# Проверка локального преподавателя

Дата испытания: 7–8 сентября 2026 года. Модель Qwen3-8B-Q4_K_M, движок llama.cpp b10850, компьютер Ryzen 5 5600 / 32 GB RAM / RTX 3070 Ti 8 GB. Все ответы в JSON получены реальным локальным выводом модели. Они не подставлены тестовым кодом.

## Итог

Техническая работа локальной модели подтверждена. **Педагогическое качество модели не принято.** Визуальные занятия и проверяемый локальный контент должны оставаться основным учебным маршрутом. Генеративный диалог — экспериментальное дополнение; его ответы не должны повышать прогресс и заменять проверку заданий.

## Фактические проверки

- Официальные веса 5 027 783 488 байт скачаны из репозитория Qwen с фиксированным revision. SHA256 повторно проверен по реальному файлу: `d98cdcbd03e17ce47681435b5150e34c1417f50b5c0019dd560e4882c5745785`.
- CUDA runtime запускается автоматически в скрытом дочернем процессе. Первая техническая проверка: запуск около 6.1 секунды, первый ответ около 0.7 секунды, второй — около 0.8 секунды. Это два коротких ответа, а не обещание постоянной скорости.
- При другой нагрузке на компьютер наблюдались ответы около 7.4 секунды. Производительность зависит от доступной видеопамяти и частичной работы на CPU.
- Проверены два последовательных запроса в одном процессе. Затем два раунда по восемь запросов, каждый раунд — один сервер, четыре предмета, явный отдельный контекст для каждого запроса.
- Во втором раунде все восемь запросов завершились реальным ответом, каждый с одним вопросительным знаком в конце.
- Отсутствующий runtime вернул понятный ответ об ошибке за 2 мс; внутренние пути, RPC и JSON не попали в этот ответ.

## Следующий шаг

Сравнить более качественные локальные модели на том же наборе и расширенной предметной выборке. Нужен контроль фактов и педагогических переходов, а не дальнейшее усложнение одного системного текста. До этого не считать свободный генеративный диалог надёжным источником исторических фактов.

Файлы доказательств: `model-transport.json`, `model-pedagogy-before-grounding.json`, `model-pedagogy.json`. Они содержат фактические запросы, контексты и ответы. `questionCount` — механическая проверка формы; это не проверка правильности.
