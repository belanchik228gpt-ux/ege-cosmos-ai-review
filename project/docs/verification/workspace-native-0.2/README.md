# Нативная приёмка карточек, настроек и документов 0.2.0

8 сентября 2026 года выполнен `scripts/workspace-native-review.mjs` на установленном `test-results/installed-app/EGE Cosmos.exe`. Перед запуском сверён архив приложения: SHA-256 `aacc72fee1736e3de872d274dc183a59218fe28d9bfc07dd2a5e63fe5db17366`. Изолированный профиль создавался через настоящий первый вход; рабочая память пользователя не изменялась. Модель не запускалась.

18 проверок прошли, ошибок renderer нет. [Результат](results.json) содержит точные размеры области каждого снимка. При запросе 390 px Electron ограничивает окно минимальной шириной; фактическая область составляет 604 px. Снимки `fullPage` включают прокручиваемое содержимое; это реальные изображения renderer EXE, а не макеты и не снимки всего рабочего стола.

Проверены главный экран, семь разделов настроек, поиск источника и переход между страницами по шесть карточек, 21 позиция базового ЕГЭ, четыре цветные вкладки темы, предпросмотр документа и пять настоящих экспортов. Четыре вкладки открывались поочерёдно — активной остаётся одна. Поиск OpenStax вернул подходящие материалы, очистка вернула первую страницу. Путь документа появляется в сохранённой памяти после физического экспорта.

PDF, HTML, DOCX, MD и TXT прочитаны с диска, размеры и SHA-256 записаны в [exports.json](exports.json). Для PDF и DOCX дополнительно проверены сигнатуры. [Настоящий PDF-конспект](absolute-lesson.pdf) отрисован в шесть PNG: [результат рендера](pdf-pages/render.json). Все шесть страниц лично просмотрены. Числовые прямые, формулы, четыре разобранных примера и ответы 1–5 читаются; версия источника — 0.2.0. Заголовки не остаются без первого абзаца, короткий список ответов не разделён. Длинное содержание продолжает перетекать между колонками; последняя страница источников заполнена только слева. DOCX не проходил визуальную проверку в Word/LibreOffice.

Лично просмотрены реальные главный экран, карточки темы, источники на обычной и узкой ширине, библиотека знаний на двух ширинах, документы, материалы и недельный календарь. Обнаруженная ранее обрезка кнопок на 604 px отдельно проверена и устранена в [ученическом маршруте](../study-flow-native/README.md). В нескольких быстрых снимках библиотеки виден закрываемый пользователем тост последнего экспорта; он не является частью учебного текста.
