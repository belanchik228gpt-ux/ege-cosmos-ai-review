Ограничения и замечания этой конкретной сборки:

1. В `02-active-day-1280.png` и `04-day-resumed.png` полоса плана увеличивает высоту рабочего экрана: в первом viewport видна лишь верхняя часть textarea. Полная видимость ввода доказана для обычной комнаты, а для учебного дня всё ещё требуется прокрутка.
2. HTML честно сообщает «Итог модели не запрашивался», но общий заключительный текст всё равно говорит, что итоги сформулированы моделью. Для сценария без модели эта условная подпись неточна.
3. 5000 мс активности интерфейс округляет до 0 минут. Исходные данные сохраняют 5000 мс; это формат вывода, а не потеря измерения.
4. Кадр `08c-basic-exam-position17.png` снят после возврата страницы к верху и показывает заголовок путеводителя, но не саму раскрытую карточку 17 ниже. Работа карточки подтверждена UI-проверкой видимости, однако личную визуальную приёмку её текста по этому PNG не заявляем.
5. В сохранённой завершённой комнате (`08-composer-1280.png`) левый маршрут отмечает предшествующие этапы галочками, хотя самостоятельной практики не было. Подпись говорит об этапах разговора, а данные знаний остаются нулевыми; галочки нельзя считать доказательством освоения.
