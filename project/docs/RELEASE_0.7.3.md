# Cosmos 0.7.3 — отдельный разбор домашних заданий

## Сделано

В левом меню обоих режимов появился самостоятельный раздел «Домашние задания». В нём можно выбрать один из 12 поддерживаемых предметов и доступный класс, ввести своё условие или прикрепить PNG/JPEG до 10 МиБ. Привязка к произвольной теме каталога больше не нужна. Работы, сообщения, итоги и конспекты хранятся отдельно от школьных занятий и подготовки к ЕГЭ; домашняя работа не увеличивает освоение темы в каталоге.

Диалог использует существующее подключение OpenAI, поток состояния, конечный таймаут и обязательную ограниченную проверку ответа. Педагогические инструкции требуют уточнить условие, объяснять по одному шагу, отвечать по смыслу, менять подсказку при затруднении, проверить самостоятельную попытку и предложить аналогичный пример. Задание ученика не маркируется официальным материалом ФИПИ. Итог с помощью преподавателя не считается самостоятельным освоением.

Фото хранится отдельным проверенным локальным файлом; в учебном состоянии сохраняются только ID и название. Восстановление фото происходит при возвращении к работе. При потере файла можно прикрепить условие повторно, и новая ссылка сохраняется. После прерванной проверки рукописи исходная фотография не подменяет недоступное вложение решения: приложение просит повторно отправить сохранённый лист.

Математический лист показывает исходное условие над белой областью решения. Оно остаётся на месте при прокрутке, фото можно увеличить и закрыть без потери штрихов. PNG и запрос проверки используют одно составное изображение: условие сверху, область «МОЁ РЕШЕНИЕ» снизу. Исходные 1400×900 пикселей рисунка сохраняются без преобразования. Для нового вопроса Cosmos есть отдельная кнопка «Лист для вопроса Cosmos» с собственным условием и отдельным черновиком.

Есть поиск прошлых работ, возврат через историю слева, заметки, завершение с отчётом и конспекты домашних работ со всеми классами в одном списке. Экспорт использует существующий тёмный шаблон с рисунками и формулами. Наименование файла появляется только после успешного экспорта.

## Проверено

- Полный набор: 1176 тестов в 72 файлах; после последних изменений — повторные 52 профильных теста. TypeScript и production build прошли.
- Новый компонент листа: реальные pointer events, увеличение и Escape, прокрутка, 1280×720 и 700×850, экспорт. Нижние 1400×900 пикселей составного PNG попиксельно совпадают с исходным рисунком. Это компонентная браузерная проверка, отдельно от EXE.
- Реальный собранный EXE и настоящие ответы OpenAI на отдельном QA-профиле: чтение фото `3(x − 2) = 15`, первый шаг без готового ответа и с рисунком; правильная проверка написанных на листе переходов `3x − 6 = 15`, `3x = 21`, `x = 7`; новый пример `4(x − 3) = 20`; текстовая домашняя работа по химии о коэффициентах и индексах, также с рисунком.
- Эти три реальные реплики заняли примерно 21, 25 и 24 секунды. Ограниченная локальная сверка — менее 3 мс. Её статус в этих случаях честно означает отсутствие покрываемого числового утверждения, а не доказанную правильность всего ответа.
- Настоящий файл PNG 1400×1324, настоящий HTML-конспект с формулами и кадрами рисунка; визуальный просмотр экспортированного HTML.
- Полное закрытие и повторный запуск EXE: восстановлены фото, переписка, штрихи и итог. Прогресс школьного режима и ЕГЭ не пополнился тестовыми домашними работами.
- Окончательная сборка: 1920×1080, 1280×720 и узкое окно 760×900, закрепление условия при прокрутке, увеличение фото, отдельный пустой лист нового вопроса, экспорт, история и отсутствие ошибок renderer.
- Два дополнительных сценария восстановления в реальном EXE с явно указанными имитациями сбоя на копии QA-профиля: потеря файла фото → повторное прикрепление → новый постоянный ID → перезапуск; неотвеченная ученическая рукопись → перезапуск → просьба повторно отправить лист. Фото совпало с оригиналом побайтно, штрихи сохранились. При попытке продолжить прерванную проверку исходное фото не было отправлено вместо решения: 0 обращений к преподавателю и 0 лишних ученических реплик. Ответы преподавателя не подставлялись. Отчёт: `docs/verification/homework-recovery-0.7.3/report.json`.

Скрипты приёмки: `scripts/homework-desk-smoke.mjs`, `scripts/homework-installed-review.mjs`. Доказательства: `docs/verification/homework-0.7.3/`, `docs/verification/homework-final-0.7.3/`, `docs/verification/sheet-assignment-component/`.

Технический след промежуточных проверок: исправлены неверное имя кнопки в QA-скрипте, ожидание приветственного окна и ссылка Playwright на окно до перезапуска. Браузерный просмотр экспорта использует установленный Edge. Финальные отчёты проходят; эти ошибки инструмента проверки не выдавались за ошибки обучения.

## Ограничения и не реализованное

Пошаговый диалог в новом разделе требует подключения OpenAI; отдельного нового локального преподавателя здесь нет. Без соединения доступны сохранённое условие, переписка, лист, заметки и завершение без ответа модели. Автоматическая сверка не гарантирует правильность произвольного объяснения и не выполняет постоянный интернет-поиск. Разбор всех видов почерка и всех задач по каждому из 12 предметов не объявляется проверенным: реальные новые запросы этой партии проверены на математике и химии.
