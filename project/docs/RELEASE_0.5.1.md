# EGE Cosmos 0.5.1 — лист для решения и практика номеров ЕГЭ

## Изменения

- Широкий чат по умолчанию; план занятия раскрывается отдельно. Рисунок открывается целиком с тем же состоянием воспроизведения, управлением кадрами, паузой и выходом по Esc.
- Математический лист 1400×900: карандаш, ластик, прямая, прямоугольник, овал, текст, цвет, толщина, сетка, масштаб, отмена/повтор, очистка с отменой. Черновики разделены по занятию и текущему примеру серии, сохраняются между перезапусками.
- Кнопка проверки отправляет фактический PNG в подключённый OpenAI. Нечитаемые знаки требуется уточнять до оценки. Локально сохранённый черновик и его экспорт доступны без модели; автоматический разбор этой новой функции требует OpenAI.
- «Скачать PNG» использует файловый модуль установленного приложения: проверяются формат, размеры, декодирование, фактическая запись и размер файла. Пустой после стирания лист не отправляется на проверку.
- «Как решать ЕГЭ»: 94 карточки — базовая математика 21, русский 27, история 21, обществознание 25. Требования, формат, авторские советы и источники разделены; основа — окончательные материалы ФИПИ 2026. Подробнее: [EXAM_WORKSHOP.md](EXAM_WORKSHOP.md).
- Серии 1–30 примеров с текущим номером, числом разобранных работ и отдельным учётом пропусков. У каждого математического примера собственный лист. Следующий пример не наследует прежнее изображение или его подпись. Неуспешные и отменённые запросы не увеличивают счётчик.
- Конспект содержит кадры фактических рисунков разговора, пояснения и формулы KaTeX. HTML/PDF используют общий тёмный макет; текстовые форматы сохраняют текст. Длинные подписи/формулы переносятся на продолжения с номером кадра.

## Ошибки, найденные в ходе работы

Отмена ластика могла сохранять новый массив штрихов вместо предыдущего; исправлен захват прежнего состояния. Canvas освобождает захват указателя и прекращает штрих после отпускания кнопки. PNG через обычный браузерный download не создавался в EXE — добавлен проверяемый файловый IPC. Полный экран потребовал разрешения Electron только для окна Cosmos; выход по Esc обработан явно. При переходе между примерами не переносится подпись старого фото. Для повторной отправки листа модель получает явное указание, что это новый снимок, который ученик мог исправить.

Часть ранних native-прогонов испорчена запущенным на компьютере AutoClicker: регулярные внешние клики были записаны в журнале событий. Приостановить повышенный процесс из этой сессии не удалось. Тестовое окно стало игнорировать нативные внешние клики; Playwright передавал события указателя в настоящий canvas собранного EXE. Обычный запуск Cosmos такого ограничения не имеет. AutoClicker не остановлен и его настройки не менялись.

## Границы выпуска

**Заблокировано:** технических блокеров в перечисленных проверенных сценариях не осталось. Повышенный AutoClicker продолжает отправлять внешние клики; перед ручным занятием его следует выключить. Остановить этот чужой повышенный процесс из текущей сессии не удалось, его настройки не менялись.

**Не реализовано в этом выпуске:** рисование в остальных предметах; полный офлайн-анализ нового рукописного листа без OpenAI; включение штрихов в JSON-резервную копию; универсальная экспертная проверка любого варианта и любого почерка. Школьный режим для всех предметов 8–11 классов остаётся отдельным следующим заданием.

«Разобрано» не означает «верно самостоятельно». Модель может ошибаться; карточки требований не являются банком официальных упражнений или заменой эксперта ЕГЭ. Живая приёмка всей серии из 10 примеров и всех 94 номеров не проводилась: конфигурация 10 проверена в UI, живое прохождение — на 2 примерах. Материалы других экзаменационных лет требуют отдельной сверки. Автоматической независимой сверки каждого облачного ответа со всеми первоисточниками нет.

Рисование пока только в математике. История штрихов хранится в локальном профиле Chromium и пока не входит в JSON-резервную копию учебного состояния; PNG можно сохранить отдельно. Исходное фото сохраняется в памяти открытого разговора для уточнений; после перезапуска нужно повторно отправить лист или прикрепить фото. Конспект сохраняет название выбранного занятия; при обсуждении посторонней темы название можно исправить в редакторе. В PDF вошли учебные рисунки и текст проверки рукописи; исходные PNG рукописей сохраняются отдельно.

## Утренний маршрут проверки

Открыть Cosmos → «Как решать ЕГЭ» → базовая математика → № 3 → 10 примеров → «Начать серию». Получить одно условие, открыть «Решить на листе», написать решение мышью и нажать «Проверить решение». После разбора перейти к следующему примеру; пропуск не засчитывается как разобранная работа. В конце получить итог и сохранить конспект через «Мои конспекты».

Дать задание расширить Cosmos до школьной программы 8–11 классов по официальным программам и проверенным учебникам: добавить все школьные предметы, включая физику и химию, исключить технологию и ИЗО; из иностранных языков оставить только английский. Сделать полноценный школьный режим, а подготовку к ЕГЭ сохранить отдельно.
