## 3. Визуальная система и формулы

- Шкала отступов 4/8/12/16/24/32 применена к основной оболочке, школе, каталогам, планам, конспектам, настройкам и адаптивным стилям. Отступы, резервирующие **физическую ширину сайдбара и высоту topbar**, сохранены как геометрия раскладки; их нельзя уменьшать до 32 px.
- Шкала текста 12/14/16/20/24/32, заголовки 24/20/16. Пользовательский масштаб текста остаётся рабочим.
- В основной оболочке единые фон, две поверхности, фиолетовый акцент, основной/вторичный текст, успех/ошибка. Контролы 6 px, карточки 10 px, модалки 14 px; одна мягкая тень. Цвета учебных рисунков и альтернативные пользовательские палитры не переопределены.
- Под текстом героя overlay `rgba(10,8,20,.55)` и blur 2 px. Дополнительная подложка 0.2 гарантирует читаемость даже на белом участке видео: расчёт по фактическим CSS-цветам даёт **5.407:1**. Это проверка наихудшего цвета, а не заявление о просмотре каждого кадра TON.
- Все интерактивные элементы получают focus-visible 2 px, включая портальные диалоги. На проверенных экранах нет кнопок без доступного имени. Скрытый мобильный сайдбар не принимает фокус.
- KaTeX уже был установлен. Ошибка была в обычном `<p>{material.intro}</p>` и других обходах TutorMarkdown. Исправлены UI-поля SchoolRoom, CloudRoom, SchoolWorkspace, TaskBoard и KnowledgeLibrary. Проверены `$1$`, `$(0;0)$`, `\(…\)`, `\[…\]` и безопасный вывод HTML/ссылок.

## Воспроизведение

```powershell
cd project
pnpm install
git lfs pull
pnpm build
pnpm test
node scripts/interface-cleanup-review.mjs
$env:COSMOS_NATIVE_REVIEW = '1'
$env:COSMOS_ELECTRON = 'C:/path/to/electron.exe'
node scripts/interface-cleanup-review.mjs
```

Тестовый скрипт не читает профиль владельца. Для браузера можно передать `COSMOS_CHROME`; native Electron берётся из `COSMOS_ELECTRON` или локальных node_modules.
