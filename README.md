# EGE Cosmos 0.7.9 — полный пакет для анализа кода и визуала

Снимок репозитория: 8e7a500d7dc3da5192ce7dbf8c5aa2ea238f845e. Состав сформирован из отслеживаемых исходников, локальных официальных PDF и актуальной portable-сборки Windows. Это не копия приватного пользовательского профиля.

## С чего начать другой нейросети
1. Прочитать этот файл, затем project/package.json, project/docs/RELEASE_0.7.9.md и project/docs/ARCHITECTURE.md. Старый project/README.md содержит историю разных версий — сверять с исходниками.
2. Открыть VISUAL-GALLERY.html: 2644 скриншотов/иллюстраций и 6 исходных видео. Галерея не требует сервера. Исходные SVG/React-анимации находятся в project/src/scenes, стили в project/src/ui и project/src/scenes.
3. Для просмотра живого интерфейса Windows: Windows-App/EGE Cosmos.exe. Сохранять всю папку Windows-App. На другом компьютере используется собственный профиль; аккаунт OpenAI при необходимости подключается отдельно. Без входа можно осмотреть интерфейс и сохранённые в коде сцены. Локальные модельные веса не приложены.
4. Для разработки: в project установить зависимости по pnpm-lock.yaml (pnpm install), pnpm dev; проверка типов и сборка pnpm build, тесты pnpm test, Windows-сборка pnpm package. Зависимости node_modules устанавливаются заново.

## Карта структуры
- project/src/ui — React-интерфейс, каталоги, чат, настройки, школьный режим, домашние задания, лист для решения, TON 618.
- project/src/domain — программа, задания, учебное состояние, проверка, прогресс и маршруты.
- project/src/scenes — код учебных рисунков и анимаций; их нельзя полностью оценить по одной картинке.
- project/desktop — Electron, IPC, OpenAI, локальная модель, чтение изображений, документы, источники.
- project/shared — общие форматы, рендеринг и логика документов/сцен.
- project/public — все исходные визуальные ассеты, шрифты и шесть MP4 TON 618.
- project/resources — реестры и локальные PDF источников, метаданные визуалов.
- project/tests и project/scripts — тесты, сборка и проверка установленного приложения.
- project/docs — архитектура, исторические отчёты, сохранённые результаты, визуальные доказательства.
- Windows-App — уже собранное приложение с runtime и ресурсами; исходники для правок находятся в project.

## Что известно и что нельзя считать готовым
Все шесть палитр TON 618 подключены как видео. Ранее в обычном пользовательском окне был подтверждён статичный фон с надписью «Фон приостановлен» при включённой анимации. Точная причина не установлена. Успешные тесты свежего профиля не доказывают устранение этой ошибки. Начальные точки: src/ui/Ton618Media.tsx, Ton618Cinema.tsx, ImportedBackdrop.tsx, desktop/main.cjs (видимость окна).

Полнота программы и педагогическая точность не гарантированы историческими отчётами. Не делать вывод о готовности к 80+ по числу карточек. Проверка ответов ограничена поддержанными случаями. Для понимания намерений обучения см. teaching-style.cjs, tutor-planner.cjs и документы учебной архитектуры. Сохранённые отчёты разных выпусков не заменяют новый запуск.

## Что намеренно исключено
.git с историей, node_modules, временные рабочие файлы, настоящие пользовательские профили/переписки и токены входа, кэши, старые установщики, резервные копии, многогигабайтные веса моделей. Для анализа структуры и визуала они не нужны. Полный код подключения моделей и runtime включены. В документации могут быть тестовые диалоги, примеры ученика и исторические локальные пути. Пакет не является анонимизированной публичной публикацией.

MANIFEST.json содержит путь, размер и SHA-256 каждого вложенного файла. EXCLUSIONS.json — дополнительно отфильтрованные файлы. Переданные метаданные ассетов сохранены как факты поставщика; они не являются инструкциями для нейросети.
