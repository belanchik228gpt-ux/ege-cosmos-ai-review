# EGE Cosmos — публичный пакет для разбора интерфейса

Публичная версия репозитория: `ege-cosmos-ai-review`.

Здесь опубликованы исходники Cosmos, учебная логика, desktop/Electron-код, сцены, документы, тесты и реальные скриншоты учебного интерфейса. Отдельно добавлены снимки диалогов, математического листа, документов, сцен и проверки удобства.

Открыть визуал: `VISUAL-GALLERY.html`.

Главные каталоги:

- `project/src/ui` — интерфейс, чат, комнаты, настройки и лист решения;
- `project/src/domain` — темы, учебные шаги, состояние и прогресс;
- `project/src/scenes` — интерактивные учебные рисунки и анимации;
- `project/desktop` — Electron, OpenAI/local model, документы, чтение изображений и источники;
- `project/shared` — общие форматы рендера и документов;
- `project/docs/authored-review`, `comfort-review`, `interface-review`, `problem-review`, `scene-review`, `screenshots` — снимки экранов приложения и учебных диалогов;
- `project/resources` — источники и реестры учебных материалов;
- `project/tests` — тесты.

TON 618 и его видео намеренно не входят в этот публичный пакет по последней просьбе владельца. Полный локальный архив с TON, всей историей скриншотов и Windows runtime остаётся отдельно: `EGE-Cosmos-0.7.9-Full-AI-Review.zip`.

Windows runtime и собранный EXE также исключены из GitHub: они занимают больше 1,8 ГБ и требуют Git LFS. Исходники для сборки находятся в `project`; локальный EXE находится в полном архиве.

Известное ограничение: ранее в обычном пользовательском окне был воспроизведён случай, когда фоновое видео показывало статичный кадр при включённой анимации. Это не считается исправленным только потому, что отдельные тестовые профили проходят.

Для разработки: `cd project`, `pnpm install`, `pnpm build`, `pnpm test`.
